# 沉浸自习室 Immersive Study Room

一个帮助你沉浸式学习的桌面应用，集场景氛围、白噪音、番茄钟计时于一体。

## 功能

### 场景系统
- 12 个精美场景背景（雨天书房、海边日落、雪夜壁炉等）
- 每个场景搭配独立背景音乐
- 滚轮或点击切换场景
- 支持自定义上传背景图片

### 音频系统
- **轻音乐** — 12 首免费学习音乐，可独立调节音量
- **环境音** — 雨声、壁炉、风声、雷声、键盘、鸟鸣
- **白噪音** — 白噪音、粉噪音、棕噪音
- 所有音轨可自由混搭

### 计时器
- **番茄钟模式** — 标准 25/5/15 分钟，可自定义
- **自定义模式** — 自由设定专注时长
- **正计时模式** — 秒表计时
- 番茄钟轮次可视化

### 数据统计
- 今日/本周/本月学习时长
- 90 天学习日历热力图
- 专注分数（基于连续学习时长）
- 每日/每周学习目标追踪

### 其他
- 4 种全局主题（暖阳/冰蓝/森林/深夜）
- 学习笔记快速记录
- 每日格言（爱情 + 奋斗主题）
- 呼吸练习引导
- 全局搜索（按 `/`）
- 场景预设 / 氛围设置
- 数据导出
- 动态粒子背景动画
- 恢复默认设置

## 快捷键

| 按键 | 功能 |
|------|------|
| `空格` / `P` | 开始/暂停计时 |
| `1-9` / `0` | 快速切换场景 |
| `M` | 音乐面板 |
| `N` | 环境音面板 |
| `B` | 白噪音面板 |
| `S` | 场景面板 |
| `G` | 学习目标 |
| `C` | 学习日历 |
| `F` | 专注分数 |
| `T` | 主题切换 |
| `L` | 学习笔记 |
| `A` | 氛围设置 |
| `H` | 说明面板 |
| `Q` | 每日格言 |
| `/` | 全局搜索 |
| `F11` / `Alt+F` | 专注模式 |
| `Ctrl+R` | 呼吸练习 |
| `Esc` | 关闭所有面板 |

## 技术栈

- Electron 33 + Vite
- React 19 + TypeScript
- Zustand 状态管理
- Howler.js 音频播放
- Web Audio API 环境音/白噪音生成
- Tailwind CSS 4

## 开发

```bash
# 安装依赖
npm install

# 开发模式
npm run dev

# 构建
npm run build

# 打包 Windows 安装包
npm run build:win
```

## 项目结构

```
src/
├── main/              # Electron 主进程
│   ├── index.ts       # 窗口创建、IPC 注册
│   ├── preload.ts     # 预加载脚本
│   ├── database.ts    # SQLite 数据库
│   └── store.ts       # electron-store 配置
├── renderer/          # React 前端
│   ├── components/    # UI 组件
│   ├── stores/        # Zustand 状态管理
│   ├── hooks/         # 自定义 Hooks
│   ├── utils/         # 工具函数
│   └── styles/        # 全局样式
└── shared/            # 共享类型
resources/
├── scenes/            # 场景背景图片
├── sounds/            # 背景音乐文件
└── icons/             # 应用图标
```
