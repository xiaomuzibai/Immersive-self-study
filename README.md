# 🌙 沉浸式自习室

> **关上世界的门，打开学习的窗。**

一个帮你沉浸式学习的桌面应用——12 个场景世界、白噪音混搭、番茄钟节奏、90 天成长热力图。

不是又一个计时器，是**一间只属于你的房间**。

---

## 🎧 白噪音混搭引擎

三条独立音轨，自由叠加，调出你专属的**专注频率**：

| 类别 | 音源 |
|------|------|
| **轻音乐** | 12 首免费学习音乐（Mixkit 授权） |
| **环境音** | 🌧 雨声 · 🔥 壁炉 · 💨 风声 · ⚡ 雷声 · ⌨️ 键盘 · 🐦 鸟鸣 |
| **白噪音** | 白噪音 · 粉噪音 · 棕噪音 |

每条音轨独立音量滑块，像调音台一样精确控制。存下你的配方，一键切换。

> 你调出的那个配比，全世界只有你一个人用。**这就是你的专注密码。**

## 🍅 番茄钟，但不只是倒计时

三种模式，找到你的节奏：

- **番茄钟模式** — 标准 25/5/15 分钟，可自定义，轮次可视化
- **自定义模式** — 自由设定专注时长
- **正计时模式** — 秒表计时，不想被时间绑架的时候

专注时自动播放预设音轨组合，休息时缓缓淡出。

> 不是在"计时"，是在**培养节奏**。

## 📊 90 天热力图 — 看见自己在变好

- 今日 / 本周 / 本月学习时长
- 90 天学习日历，一眼看见坚持的痕迹
- 专注分数（基于连续学习时长）
- 每日 / 每周学习目标追踪

> 不是焦虑地数时间，是**看见自己在变好**。

## 🫁 呼吸练习

学不下去的时候，按 `Ctrl+R` 启动 **4-7-8 呼吸引导**：

吸 4 秒 → 屏 7 秒 → 呼 8 秒

配合柔和的视觉动画和音效，3 个循环就能平静下来。

> 学习不只是输入知识，也是**照顾好自己**。

## 🛠️ 开发

```bash
npm install          # 安装依赖
npm run dev          # 开发模式
npm run build        # 构建
npm run build:win    # 打包 Windows 安装包
```

### 技术栈

Electron 33 · Vite · React 19 · TypeScript · Zustand · Howler.js · Web Audio API · Tailwind CSS 4

### 项目结构

```
src/
├── main/              # Electron 主进程
│   ├── index.ts       # 窗口创建、IPC 注册
│   ├── preload.ts     # 预加载脚本
│   ├── database.ts    # SQLite 数据库
│   └── store.ts       # electron-store 配置
├── renderer/          # React 前端
│   ├── components/    # UI 组件
│   ├── stores/        # Zustand 状态管理
│   ├── hooks/         # 自定义 Hooks
│   ├── utils/         # 工具函数
│   └── styles/        # 全局样式
└── shared/            # 共享类型
resources/
├── scenes/            # 场景背景图片
├── sounds/            # 背景音乐文件
└── icons/             # 应用图标
```
